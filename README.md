# Vértices Virtuais Toolbox

Plugin do QGIS (Processing) para cálculo de vértices virtuais com propagação de incertezas.

Ferramentas (Caixa de Ferramentas → *Vértices Virtuais Toolbox*):

| Grupo | Ferramenta |
|---|---|
| Vértices virtuais | Interseção Angular · Interseção Linear · Interseção de Retas · Regra do Paralelogramo |
| Eixos e linhas paralelas | Pontos para Linha (Ordenamento Espacial) · Vértices e Linhas Paralelas |

## Personalizar o painel de ajuda
Edite `ajuda.py` (link da documentação, texto do link, rodapé) e substitua
`resources/imagem_1.png` e `resources/imagem_2.png`.
